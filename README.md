# Elena Ellingsen – Developer Portfolio

This is my personal portfolio site, built to showcase the projects, skills, and experience I've gained as a fullstack developer. It reflects my passion for building fast, modern, and user-focused web applications.

> 💼 **I'm open to full-time remote roles or freelance opportunities. Let's connect!**

## 🔗 Live Demo

Check out the live site here: [ingell.github.io/portfolio](https://ingell.github.io/portfolio/)

## 🧰 Tech Stack

- **Frontend:** HTML, CSS, JavaScript, TailwindCSS
- **Template:** Alexa – Responsive Portfolio by Bedimcode (customized)
- **Hosting:** GitHub Pages

## ✨ Features

- Responsive design for mobile and desktop
- Project showcase with links
- About Me section
- Contact form (connects via email or placeholder)
- Smooth scroll and animation effects

## 🛠️ Run Locally

Clone the project:

```bash
git clone https://github.com/ingell/portfolio.git
cd portfolio

```
